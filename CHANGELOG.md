# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0-beta.1 - 2026-11-11

First public beta.

### Added

- Project-grouped chat history with alphabetical projects and newest-first chats.
- Nested forks under their source chat, based on the native `fork.sessionID` link.
- In Progress and Unread activity panel with popup navigation and hidden-activity markers.
- Pending approval and question indicators, including subagent families.
- Native per-chat menu actions: rename, fork, close, and delete.
- Project plus that opens or resumes an empty draft in the exact server and directory.
- Sidebar width persistence, collapsed groups, and collapsed fork branches.
- Compact rows, trailing title fade, and a cache-safe loading state.
- Keyboard support, RTL layout, reduced motion, and forced-colors handling.
- Projects card in Preferences using native card styling, with a single selected mode.
- Native update button placement next to Settings when an update is available.
- Automatic fallback to the standard Inbox when the host structure is incompatible.
